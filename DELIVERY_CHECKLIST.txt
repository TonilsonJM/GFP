🚀 QUICK START (5 PASSOS)

1. Execute SQL no Supabase
   → scripts/create-tables.sql

2. Verifique .env.local
   → Tem SUPABASE_SERVICE_ROLE_KEY?
   → Tem JWT_SECRET?

3. Rode o projeto
   → npm run dev

4. Teste registro
   → http://localhost:3000/auth/register

5. Teste login
   → http://localhost:3000/auth/login

🗄️ BANCO DE DADOS

Tabela: users_accounts
  - id (UUID)
  - name (TEXT)
  - email (TEXT UNIQUE)
  - password_hash (TEXT)
  - plan (FREE | PRO)
  - status (ACTIVE | BLOCKED)
  - created_at (TIMESTAMP)
  - updated_at (TIMESTAMP)

Índices:
  - idx_users_accounts_email
  - idx_users_accounts_status
  - idx_users_accounts_plan
